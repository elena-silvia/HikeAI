# RoMountainAgent - An Inteligent Mountain Guide

**RoMountainAgent** is an AI-powered assistent designed to help hikers with up-to-date,reliable information and safety reccomandation for mountain trails in Romania

The agent uses the Gemini SDK from google-genai and the interface was built and hosted on Streamlit

## Features
- **Trail information:** route dificulty, estimated time, trail markings, elevation profiles.
- The agent guides mountain lovers with water sources & shelters
- Safety First: users will found out about weather conditions, minimum equipment and salvamont numbers

## Used Technologies
- Language: Python 3.10+
- LLM: Google Gemini(gemini-3.6-flash)
- SDK: google-genai
- Interface and Cloud: Streamlit
